# 声文｜Windows 视频转文字工具

本项目提供 Windows 桌面界面和 GitHub 云端打包流程。若你不想在电脑安装 Python，请阅读 `BUILD_EXE_GUIDE.md`，通过 GitHub Actions 生成独立的 `Shengwen.exe`。

## 功能
- 选择视频并提取音频
- 语音转文字（自动检测、中文、英语、日语、韩语、法语、德语、西班牙语）
- 导出 TXT 文本与 SRT 字幕
- 导出 MP3 音频；识别流程会生成 WAV 中间音频
- 默认在视频所在文件夹下创建 `声文导出` 文件夹

## 重要说明
- 本压缩包本身不是现成的 `.exe`；需按 `BUILD_EXE_GUIDE.md` 通过 GitHub 云端生成。
- 首次识别需要联网下载语音识别模型。下载后通常可在本机离线识别。
- 识别准确度和速度受音频质量、电脑性能和模型大小影响，请校对重要内容。
