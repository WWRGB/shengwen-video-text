# 声文｜Windows 视频转文字工具（2.1 带字幕成片版）

## 功能
- 从常见视频格式提取音频并进行本机语音识别。
- 支持自动检测语言，以及中文、英语、日语、韩语、法语、德语、西班牙语。
- 支持 small、medium、large-v3 模型；默认使用 medium。
- 默认关闭 VAD 静音过滤，减少轻声、间歇性说话被过滤的风险。
- 识别结果实时显示进度；异常中断时尽可能保留已识别部分。
- 可以填写人名、专业词或专有名词提示。
- 导出 TXT、SRT、MP3、WAV，并复制文字。
- **新增：生成带硬字幕的 MP4 视频**。根据识别段落的时间轴，将白色字幕和黑色描边直接渲染进视频画面，生成新文件，不覆盖原视频；播放或分享时不需要额外携带 SRT 文件。

## 生成带字幕视频
1. 选择视频并完成语音识别。
2. 如需修改错字，先检查识别结果；字幕使用识别段落及其时间戳。
3. 点击“生成带字幕视频”，选择输出路径。
4. 等待 FFmpeg 渲染完成。视频越长、分辨率越高，生成时间通常越长；输出默认是 H.264/AAC 的 MP4。

## 使用说明
最终用户无需安装 Python：请使用 GitHub Actions 构建生成的 `Shengwen-Windows-x64` Artifact。首次选择某个识别模型时需要联网下载模型文件；之后可使用本机 CPU 识别。模型越大通常识别质量越好，但需要更多下载空间、内存和处理时间。

## 从源码运行
安装 Python 3.11 后执行 `run.bat`。

## 生成 Windows EXE
GitHub Actions 使用 `.github/workflows/build-windows.yml` 自动打包。将项目文件提交到 `main` 或 `master` 分支后，在仓库的 Actions 页面查看运行结果，并下载 `Shengwen-Windows-x64` Artifact。

## 识别准确率说明
自动语音识别无法保证零错误。音质、口音、背景音乐、多人重叠说话都会影响结果。可尝试选择正确语言、使用更大模型，并在识别提示中填写人名或专业词。默认不启用静音过滤，是为了避免模型把安静或短暂语音段过滤掉。
