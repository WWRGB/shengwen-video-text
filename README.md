# 声文 · 用户可选全流程版

这是 Windows 桌面版视频语音识别、校对、翻译与字幕成片工具。默认走简单模式，常用的语种、目标翻译语言、轻度音频处理和导出选项仍可由用户选择。

## 当前实际工作流程

1. 从视频解出 16 kHz 单声道音频；默认使用 FFmpeg 的高通/低通、轻度降噪和动态音量均衡滤镜。可关闭该处理。此滤镜不等于专业人声/背景音乐分离。
2. 用多语言 Whisper 模型按 16 秒、4 秒重叠的窗口识别。自动模式会在各窗口重新估计主要语种，试图捕捉视频内的语种变化；窗口内快速切换语言、多人重叠说话和方言仍可能被识别错。
3. 对模型打分较差或语种不确定的片段尝试一次二次解码，并标记可疑文字、语言概率偏低的片段、长时间没有字幕的区间与片尾空白。概率是模型提示，不是准确率保证。
4. 将结果分别放进三个页签：**编辑稿**、**原始转写（只读快照）**、**译文（可编辑）**。原始转写不会被用户编辑稿覆盖。
5. 可选在线翻译。用户选择目标语言后，程序逐条翻译并沿用原字幕时间轴。首次发出网络翻译请求前会征求同意；只发送字幕文字，不上传视频/音频。提供者是 MyMemory 公共在线服务，语种对、可用性、隐私政策与额度取决于第三方服务；不保证支持所有语言对。
6. 生成硬字幕 MP4 时，可选用已校对的原文或已生成的译文；原视频不会被覆盖。导出 SRT/TXT、原始 TXT、译文 SRT/TXT、MP3/WAV 和 CSV 校对表。

## 编辑行为

“编辑稿”和“译文”按每行对应一条字幕。可以修改某行文字；为了不破坏时间轴，当前这两个编辑框不允许直接增加/删除行。若需要拆分或合并字幕，请在剪辑软件中处理，或后续为软件增加时间轴编辑器。导出前如果行数和字幕条数不一致，程序会阻止导出并提示。

编辑原文后，旧译文会被标记为过期，需要重新翻译，避免译文和当前原文不一致。

## 语言与方言说明

- 使用 faster-whisper 的多语言 Whisper 模型识别其覆盖的多种主要国际语言。
- 自动语种检测以短时间窗口为单位，不是对每个词的语言做精确分类。很短的切换、少见语言和方言可能错分。
- 口音/方言/专有词提示会作为 Whisper 初始提示；它不是专门训练的方言分类器，不保证理解所有地方变体。
- 在线翻译是可选步骤。用户拒绝网络翻译时，原文识别、导出和硬字幕功能仍可使用。
- 任何 ASR 或机器翻译都可能出错。校对表是风险提示，不等于通过了人工验证。

## 系统要求与第一次使用

- 64 位 Windows；联网用于首次下载 Whisper 模型，以及用户主动运行在线翻译时。
- 第一次识别会下载所选模型。medium 是默认均衡档；large-v3 通常更慢、占用更多内存。
- 纯 Python 源码需要 Python 3.10+ 运行；若下载 GitHub Actions 的 `Shengwen-Windows-x64` Artifact，则无需单独安装 Python。

## 从现有 GitHub 仓库更新

最简单的方式是在已有仓库根目录替换 `main.py`，同时更新 `README.md`、`requirements.txt`；保留 `.github/workflows/build-windows.yml`。提交后查看 Actions，编译成功后从 Artifact 下载 `Shengwen-Windows-x64`。
